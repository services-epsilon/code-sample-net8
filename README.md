# code-sample
Exemple de code .NET et Angular

## Projects

This repository contains two projects:

1. **Project A**: A sample web application built with ASP.NET Core. It demonstrates the use of modern web development practices and features in .NET.
2. **Project B**: An Angular project

## Getting Started

To get started with these projects, follow the instructions below.

### Prerequisites

- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
- [Node.js](https://nodejs.org/) (for Project B)
- [Angular CLI](https://angular.io/cli) (for Project B)

### Installation

1. Clone the repository:
    ```sh
    git clone https://github.com/services-epsilon/code-sample-angular-net
    cd code-sample-angular-net
    ```

2. Navigate to Project A and restore dependencies:
    ```sh
    cd ConsoleApp
    dotnet restore
    ```

3. Navigate to Project B and install dependencies:
    ```sh
    cd ../ConsoleApp
    yarn install
    ```

### Running the Projects

#### Project A

To run the ASP.NET Core web application:
```sh
cd ProjectA
dotnet run
```
The application will be available at `https://localhost:5001`.

#### Project B

To run the Angular project:
```sh
cd ProjectB
ng serve
```
The application will be available at `http://localhost:4200`.
